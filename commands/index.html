    Quick Reference¶

    Get Help¶

    # Show all commands
cockpit --help

# Get help for specific command
cockpit <command> --help

# Get help for subcommand
cockpit <command> <subcommand> --help

    Global Flags¶

    All commands support these global flags:

    --language [en-us|pt-br]    # Set language
--log-level [debug|info|warn|error]  # Set log level
--help                      # Show help
--version                   # Show version

    Documentation Guidelines¶

    For Users¶

    Each command documentation includes: - Overview - What the command does - Usage - How to run the command - Description - Detailed explanation - Flags - Available options - Arguments - Required/optional inputs - Examples - Common use cases - Output - What to expect - Exit Codes - Success/failure indicators - Troubleshooting - Common issues and solutions

    For Developers¶

    When adding a new command:

    1. Create the command file in cmd/ 

      // cmd/mycommand.go
func NewMyCommand(...) *cobra.Command {
    return &cobra.Command{
        Use: "mycommand",
        Short: "Short description",
        RunE: func(cmd *cobra.Command, args []string) error {
            // implementation
        },
    }
}

    2. Register in root command (cmd/root.go) 

      rootCmd.AddCommand(NewMyCommand(log, cfg, t))

    3. Create documentation (docs/commands/mycommand.md)

    4. Use COMMAND_TEMPLATE.md as reference
    5. Document all flags and arguments
    6. Provide examples

    7. Include troubleshooting

    8. Update this README (docs/commands/README.md)

    9. Add command to index

    10. Update command categories

    11. Keep documentation in sync

    12. Update docs when command changes
    13. Update examples if behavior changes
    14. Document new flags/arguments

    Command Naming Conventions¶

    Command Names¶

    • Use lowercase
    • Use single words when possible
    • Use hyphens for multi-word commands (e.g., my-command)
    • Keep names short and descriptive

    Flag Names¶

    • Use lowercase
    • Use hyphens for multi-word flags (e.g., --my-flag)
    • Use short flags for common options (e.g., -f for --force)
    • Be consistent with common conventions

    Subcommand Names¶

    • Use lowercase
    • Use verbs when appropriate (e.g., list, create, delete)
    • Keep consistent with similar commands
